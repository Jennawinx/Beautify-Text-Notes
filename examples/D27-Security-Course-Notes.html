RSA
Generates a key pair
Using math with prime numbers
1.
Pick p and q two large prime numbers and calculate n = p . q
2.
Compute z = (p-1).(q-1)
3.
Pick e prime < z s.t. e and z are relative primes
<- (e, n) is the public key
4.
Solve e * d = 1 ( mod z ) to find d
<- (d, n) is the private key
    Public Key      Kp = (e, n)
    Private Key     Ks = (d,n)
Encryption : E_kp(m) = m^e mod n = c
Decryption : D_ks(c) = (m^e)^d mod n = (m^d)^e mod n = m

The Network Layer

Transport Layer

TCP - Transmission Control Protocol
The sender divides data-stream into packets sequence number is attached to every packet
The receiver checks for packets errors, reassembles packets in correct order to recreate stream
ACK (acknowledgements) are sent when packets are well
received and lost/corrupt packets are re-sent
=> Connection state maintained on both ends (See 3-way handshake)
        ATTACK: Port Scanning                                                       (Confidentiality)
